## 2026-11-27 · 目录整理与文档

- 前端迁入 `frontend/`，页面、CSS、画布编辑和工作流代码分别存放。
- 后端迁入 `backend/`，将 HTTP 接口与单帧成果读写拆到不同模块，并集中定义项目路径。根目录保留 `app.py` 和双击启动器。
- 模型准备和 GrabCut 批处理命令归入 `scripts/`，依赖及模型清单归入 `config/`。测试按 Python、浏览器和共用测试样例分目录。
- 新建 `docs/`，收录架构、使用、部署、测试和本变更日志。更新部署自检命令。真实 SAM 浏览器测试可指定一帧采集，测试使用临时副本。
- 终端调用模型准备改用 `python3 -m scripts.prepare_models`，传统批处理改用 `python3 -m scripts.batch`，旧 SAM 对比批处理改用 `python3 -m backend.sam_batch`。命令从项目根目录运行。

## 2026-11-21 · 复核界面、失败记录与导出

- 增加 iToF／双目筛选、相机标识、分割与复核进度，缩小工具区。确认掩码保存成功后可以自动切换到当前列表的下一张。
- 将失败原因和处理状态纳入筛选 CSV，并随成果导出完整失败历史。CSV 加入头侧方向。
- 支持失败帧打开原图、记录保留／淘汰／待定、备注及头侧方向。推理失败且坐标可用时，可用 SAM 或手工补做掩码。坐标校验失败的帧可填写复核意见，等待数据修复后再生成掩码。

## 2026-11-19 15:41:15 · 双输入分割和点云坐标

- `6ca68a1` 增加红外／RGB 分割选择。RGB 按实际彩色流与对齐深度标定做坐标校正，红外沿用原始深度网格。成果保存几何来源和有效区域，并提供掩码反投影函数。
